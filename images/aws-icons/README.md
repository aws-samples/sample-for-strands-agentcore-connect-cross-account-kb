# AWS Architecture Icon Assets

These assets are an unmodified subset of the official
[AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) package dated April 30,
2026. They are used by `scripts/generate_architecture_diagrams.py`.

Package:

```text
Icon-package_04302026.zip
SHA-256: 699fe7a2481aa712b6b74faff0aaab6382d3bb7243bba3abd3ba909d6bf7b912
```

Included service and resource icons:

* Amazon Bedrock AgentCore
* Amazon Bedrock
* AWS Identity and Access Management
* AWS Lambda
* AWS Security Token Service
* Amazon Redshift
* AWS account group

Use these assets according to the AWS Architecture Icons terms on the source page.
